# Pothole Detection and Road Condition Classification

AI-based system that detects potholes from road images using YOLOv8 
and classifies road condition as Good, Damaged, or Severely Damaged.

## Tech Stack
- Python, YOLOv8 (Ultralytics)
- Trained on Google Colab (GPU)
- Web interface built with Gradio

## Results
- Precision: 0.677
- Recall: 0.596
- mAP50: 0.649
- mAP50-95: 0.300

## How to Run
Open `Pothole_Detection_Project.ipynb` in Google Colab and run all cells in order.
